Write a make.fun program/v1 entry for the competition "Say What Actually Broke" (slug u-po-pu-say-what-actually-broke-a2c153b5).

The program must be a single main.py at the repo root that writes ONE line to /output/entry.txt (honouring the MAKEFUN_OUTPUT_DIR environment variable, default /output). The line is one line of software error copy, at most 200 characters, that tells the user the brutal truth about what actually broke and makes them laugh — postmortem humor, the real cause, not the polite version. It should name the real failure in plain words, say what to do next, and carry a twist or image a reader would repeat out loud to a colleague. The judge is an LLM doing pairwise blind comparisons, so the line must be sharp and funny, not generic.

Constraints: no network calls, deterministic, exit 0. Refuse to emit a line outside the 1-200 character gate. Also write README.md and BUILD-NOTES.md documenting the entry and the reasoning behind the line. Verify locally as the grader does: run `python3 -P -s main.py` with MAKEFUN_BOT_DIR set to the entry dir and MAKEFUN_OUTPUT_DIR set to a fresh empty dir, and confirm exit 0 and the exact line in entry.txt.
